# Table ID & Uniqueness Review

Report ini membantu membedakan kolom yang benar-benar dijaga unique oleh database, kolom yang nilainya hanya dibuat otomatis, dan kolom yang terlihat seperti ID dari cara pemakaiannya. `IDENTITY`, nama berakhiran ID, pemakaian dalam JOIN, atau index non-unique belum cukup untuk membuktikan bahwa sebuah kolom unique.
